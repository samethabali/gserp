💬 WhatsApp Bildirimleri

Yükleniyor…

Randevu onayı, iptal ve 24 saat önce hatırlatma mesajları Meta WhatsApp Cloud API üzerinden gönderilir. API kapalıyken booking sayfasında WhatsApp'tan Yaz butonu için salon telefonu kullanılır.

API kapalıyken wa.me linki ve müşteri iletişimi için.

📖 WhatsApp Kurulum Rehberi — Adım adım nasıl yapılır?

1. Meta Business hesabı

  1. business.facebook.com üzerinden işletme hesabınızı doğrulayın.
  2. Meta Developers → Uygulama oluştur → WhatsApp ürününü ekleyin.
  3. WhatsApp → API Setup sayfasından geçici token ile test edin; kalıcı kullanım için System User oluşturup kalıcı token alın.

2. Bu sayfadaki alanları doldurun

AlanNereden bulunur?
Access Token Meta Developers → WhatsApp → API Setup veya System User token
Phone Number ID API Setup sayfasında, test/gönderim numarasının altında
Business Account ID WhatsApp Manager → Hesap ayarları (referans amaçlı)
Salon WhatsApp Numarası Uluslararası format: +905321112233
Webhook Verify Token Sizin belirlediğiniz rastgele güçlü bir metin (Meta panelinde aynısını gireceksiniz)

3. Webhook bağlantısı

  1. Meta Developers → WhatsApp → Configuration → Webhook
  2. Callback URL: https://<salon-subdomain>/api/webhooks/whatsapp
  3. Verify token: yukarıdaki Webhook Verify Token ile birebir aynı olmalı
  4. Abone olunacak alan: messages (teslimat durumu için opsiyonel)

4. Onaylı mesaj şablonları

Meta Business Manager → WhatsApp Manager → Message templates bölümünden aşağıdaki şablonları oluşturup onaylatın (genelde 1–24 saat):

Şablon adıKategoriNe zaman gider?
appointment_request_receivedUtilityMüşteri online randevu isteği gönderdiğinde
appointment_confirmedUtilitySalon randevuyu onayladığında
appointment_cancelledUtilityRandevu iptal edildiğinde
appointment_reminderUtilityRandevudan 24 saat önce (her gün 09:00)

Her şablonda body parametreleri sırasıyla: müşteri adı, hizmet/uzman, tarih-saat (iptalde sebep). Dil: Türkçe (tr).

5. Test

  1. Bu sayfada ayarları kaydedin ve WhatsApp API bildirimlerini etkinleştir kutusunu işaretleyin.
  2. Public /booking sayfasından test randevu isteği gönderin.
  3. Veritabanında notification_log tablosunda SENT / FAILED kayıtlarını kontrol edin.
  4. Meta panel → Message insights ile teslimatı doğrulayın.

6. API kapalıyken (wa.me fallback)

WhatsApp API etkin değilse booking onay ekranında müşteriye WhatsApp'tan Yaz butonu gösterilir. Bunun için yalnızca Salon WhatsApp Numarası alanını doldurmanız yeterlidir.

7. Güvenlik ve kota

  • Access Token gizli bilgidir; kimseyle paylaşmayın ve ekran görüntüsü almayın.
  • Abonelik planınıza göre aylık WhatsApp mesaj kotası uygulanır.
  • Meta konuşma başına ücretlendirir; randevu bildirimleri genelde utility kategorisindedir.
