# GSERP — Sistem Özeti (v1.0.0)

Güncel mimari ve modül referansı. Eski MockDataStore referansları kaldırıldı; kalıcı veri PostgreSQL + Flyway migration ile yönetilir.

## Teknoloji

- **Backend:** Java 21, Spring Boot 3.4, Spring Security (JWT + form login), JPA, Flyway
- **Frontend:** Thymeleaf, Vanilla JS, FullCalendar, WebSocket (STOMP)
- **Veritabanı:** PostgreSQL 16
- **Deploy:** Docker Compose, nginx reverse proxy, salon başına izole instance

## Güvenlik (Faz 1)

- Rol tabanlı erişim: ADMIN, RECEPTIONIST, SPECIALIST, CUSTOMER
- `StaffScopeService`: SPECIALIST yalnızca kendi randevuları
- Public booking → `PENDING_APPROVAL` + `BookingRateLimitFilter`
- Parola değiştirme + ilk girişte zorunlu değişim (`must_change_password`)
- KVKK: `/privacy`, `customer.consent_at`

## Bildirimler (Faz 2)

- WhatsApp hibrit: Meta Cloud API şablonları + `notification_log`
- `AppointmentReminderService`: 24 saat önce hatırlatma
- wa.me fallback: API kapalıyken booking onay sayfası
- Webhook: `POST /api/webhooks/whatsapp`

## Ticari (Faz 3)

- Admin kullanıcı yönetimi (`/users`)
- Salon white-label (`salon_settings`, `/settings`)
- Sürüm: 1.0.0

## Modüller

- **Randevu:** `AppointmentService` — oluşturma, taşıma, onay, iptal, çoklu seans
- **Kaynak:** `ResourceLockService` — tür bazlı kapasite kilitleme
- **Zamanlama:** `SchedulerService` — çalışma saatleri ve müsaitlik
- **Audit:** `AuditService` — CREATE/UPDATE/DELETE/STATUS_CHANGE
- **Kampanya:** kupon ve sadakat indirimi
- **WebSocket:** `NotificationService` — canlı takvim senkronu
