# GSERP — Sistem Özeti (v1.1.0)

Güncel mimari ve modül referansı. Kalıcı veri PostgreSQL + Flyway migration ile yönetilir.

## Teknoloji

- **Backend:** Java 21, Spring Boot 3.4, Spring Security (JWT + form login), JPA, Flyway
- **Frontend:** Thymeleaf, Vanilla JS, FullCalendar, WebSocket (STOMP)
- **Veritabanı:** PostgreSQL 16
- **Deploy:** Docker Compose, nginx reverse proxy, multi-tenant SaaS (`salon_id` izolasyonu)

## Multi-tenant SaaS

- **Organizasyon → salon (şube)** hiyerarşisi; tenant çözümleme: `X-Salon-Slug` veya subdomain
- **Roller:** PLATFORM_ADMIN, ORG_OWNER, BRANCH_MANAGER, RECEPTIONIST, SPECIALIST, CUSTOMER
- **Abonelik:** `organization_subscription`, planlar (SOLO / FRANCHISE), WhatsApp kotası
- **Salt okunur mod:** trial süresi dolunca yazma API'leri engellenir; okuma devam eder

## Güvenlik

- Rol tabanlı API ve sayfa erişimi
- `StaffScopeService`: SPECIALIST yalnızca kendi randevuları
- Public booking → `PENDING_APPROVAL` + rate limit
- KVKK: `/privacy`, müşteri onayı

## Bildirimler

- WhatsApp Cloud API + org bazlı kota
- `AppointmentReminderService`: 24 saat önce hatırlatma
- Salon ayarları: `/settings`, `/api/settings/whatsapp`

## Ticari

- Abonelik UI: `/settings/billing`
- Onboarding: `/onboarding/wizard` (kayıt), `/onboarding/setup` (5 adım)
- iyzico webhook iskeleti: `POST /api/webhooks/iyzico`

## Modüller

- **Randevu:** `AppointmentService` — oluşturma, taşıma, onay, iptal, çoklu seans
- **Kaynak:** `ResourceLockService` — tür bazlı kapasite kilitleme
- **Zamanlama:** `SchedulerService` — çalışma saatleri ve müsaitlik
- **Audit:** `AuditService` — CREATE/UPDATE/DELETE/STATUS_CHANGE
- **Kampanya:** kupon ve sadakat indirimi
- **WebSocket:** `NotificationService` — canlı takvim senkronu
